ClientAsyncLogCollection

Гибкая утилита для сбора событий из Windows Event Log с фильтрацией по провайдерам, уровням критичности и глубине по времени. Поддерживает вывод в JSON и XML.

Ключевые возможности

  • Сбор событий из любых журналов Windows (Application, System, Security и др.)
  • Фильтрация по поставщикам (провайдерам), уровням и количеству дней
  • Умное сопоставление имён провайдеров с реальными журналами (кэширование)
  • Экспорт в JSON или XML с автоматическим разделением по папкам приложений и уровней
  • Управление через JSON-конфигурацию и/или параметры командной строки
  • Потокобезопасность, защита от повторного запуска
  • Встроенное логирование с маскированием конфиденциальных данных

Быстрый старт

# Использовать appsettings.json из папки с программой
ClientAsyncLogCollection.exe

# Указать свой конфиг и папку для сохранения
ClientAsyncLogCollection.exe --config "C:\MyConfigs\custom.json" --pl "D:\Logs"

# Только командная строка: два провайдера, уровни Error+Warning, XML
ClientAsyncLogCollection.exe --apps "Service Control Manager,.NET Runtime" --flags 2,3 -f xml
