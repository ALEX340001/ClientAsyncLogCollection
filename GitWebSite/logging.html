📝 Система логирования

В проекте используется собственная легковесная библиотека MyLogger (папка MyLogger_23-03-2026). Она предоставляет интерфейс ILogger, реализацию файлового логгера FileLogger и опциональное маскирование конфиденциальных данных через IDataMasker.

🧩 Компоненты

Класс / ИнтерфейсНазначение
ILoggerБазовый интерфейс логирования (Debug, Info, Warn, Error)
FileLoggerПотокобезопасная запись в файлы с автоочисткой и ротацией
IDataMaskerИнтерфейс для маскирования чувствительных данных
DefaultDataMaskerСтандартная реализация: скрывает токены, IP, пароли, пути
LoggingOptionsНастройки: уровень, размер файла, срок хранения, маскирование
LogLevelПеречисление: Debug, Info, Warn, Error

⚙️ Настройки логирования

Все параметры задаются через объект LoggingOptions, который передаётся в конструктор FileLogger.

СвойствоТипПо умолчаниюОписание
LogDirectorystring%Documents%\log_app_ClientAsyncLogCollectionПапка для хранения логов
MinLevelLogLevelInfoМинимальный уровень записываемых сообщений
MaxFileSizeMBint10Максимальный размер файла до ротации (МБ)
RetentionDaysint30Срок хранения логов (дни), старые удаляются
MaskSensitiveDataboolfalseВключить автоматическое маскирование данных

🔒 Маскирование данных

Если установлен флаг MaskSensitiveData = true, FileLogger пропускает каждое сообщение через реализацию IDataMasker. Стандартный DefaultDataMasker скрывает:

  • Токены (шестнадцатеричные строки длиннее 8 символов) → ***
  • IP-адреса → 192.168.***.***
  • Пароли в конструкциях password=... → password=***
  • Локальные пути Windows → C:\***
💡 Вы можете реализовать свой IDataMasker и передать его в конструктор FileLogger для кастомизации.

📁 Где находятся логи приложения

По умолчанию все логи пишутся в папку пользователя: %USERPROFILE%\Documents\log_app_ClientAsyncLogCollection. Ежедневно создаётся новый файл с именем YYYY-MM-DD_log.txt. При превышении размера файл ротируется (добавляется суффикс .1, .2 и т.д.).

🛠️ Пример использования в коде

var options = new LoggingOptions
{
    MinLevel = LogLevel.Debug,
    MaskSensitiveData = true,
    MaxFileSizeMB = 20,
    RetentionDays = 14
};

ILogger logger = new FileLogger(options);
logger.Info("Приложение запущено");
logger.Error("Не удалось подключиться к серверу", exception);
