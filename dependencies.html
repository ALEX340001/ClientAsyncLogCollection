📦 Зависимости проекта

Системные требования

  • ОС: Windows 10 / 11, Windows Server 2016+
  • .NET Runtime: .NET 8.0 (или выше)
  • Права: для чтения журнала Security требуются права администратора

Внешние библиотеки

Проект включает собственную библиотеку логирования MyLogger (папка MyLogger), которая реализует интерфейс ILogger, маскирование данных и ротацию логов.
