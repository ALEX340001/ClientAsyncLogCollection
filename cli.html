🖥️ CLI и команды

Все параметры командной строки имеют приоритет над настройками из JSON-файла.

Синтаксис

ClientAsyncLogCollection.exe [options]

Параметры

Короткий ключДлинный ключТипОписание
-c--configстрокаПуть к JSON-файлу конфигурации
-f--formatстрокаФормат вывода: json или xml
—--defaultFolderстрокаПапка по умолчанию для сохранения логов
—--plстрокаПапка пользователя (приоритетнее defaultFolder)
—--appsсписокСписок приложений через запятую
—--flagsсписокУровни событий (1–5) через запятую
-h--help—Вывод справки

Примеры

# Запуск с JSON-конфигом по умолчанию (appsettings.json)
ClientAsyncLogCollection.exe
# Указать свой конфиг и папку сохранения
ClientAsyncLogCollection.exe --config "C:\MyConfigs\custom.json" --pl "D:\Logs"
# Только командная строка: два провайдера, уровни Error+Warning, формат XML
ClientAsyncLogCollection.exe --apps "Service Control Manager,.NET Runtime" --flags 2,3 -f xml
