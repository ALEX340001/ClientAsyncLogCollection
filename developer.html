🛠️ Информация для разработчиков

Ниже описана внутренняя архитектура утилиты ClientAsyncLogCollection. Проект написан на C# (.NET 8) и состоит из трёх основных слоёв: инфраструктура логирования, ядро сбора событий и утилиты.

📦 Общая структура (слои)

  • MyLogger – независимая библиотека для файлового логирования с маскированием.
  • Core – сбор событий, поиск провайдеров, кэширование, форматирование.
  • Utils – фабрика логгера, хелперы, валидация, работа с путями.

🔍 Алгоритм сопоставления провайдеров

ProviderMapper.BuildMapping для каждого запрошенного имени выполняет:

  1. Точное совпадение – поиск в словаре реальных провайдеров без учёта регистра.
  2. Частичное совпадение – вычисляется длина наибольшей общей подстроки (Longest Common Substring) между запрошенным именем и каждым реальным именем. К результату добавляется бонус 100, если одно имя является префиксом другого. Выбирается кандидат с максимальным счётом.
  3. Fallback по первой букве – если не найдено ни одного кандидата, берётся первый реальный провайдер, имя которого начинается с той же буквы (может быть неточным, поэтому рекомендуется явное указание журнала в конфигурации).
  4. Если ничего не подошло – провайдер пропускается с предупреждением в лог.
